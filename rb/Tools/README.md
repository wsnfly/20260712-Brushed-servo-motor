# MODBUS RTU 电机控制器调试工具

## 功能特性

- 串口连接管理（支持自动扫描串口）
- 实时状态监控（位置、速度、模式、启动标志）
- 模式切换（位置模式、速度模式、待机模式、增量模式）
- 目标值设置（位置、速度）
- 设置当前位置为原点（编码器清零+目标位置同步）
- PID参数在线调整（位置环、速度环）
- 其他参数配置（死区、最大输出、电机方向、编码器方向、启动方式）
- 通信日志记录

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行程序

```bash
python modbus_debugger.py
```

## 使用说明

### 1. 连接串口
- 选择正确的串口号（如 COM3）
- 设置波特率（默认 115200）
- 设置从机地址（默认 1）
- 点击"连接"按钮

### 2. 设置模式
- 点击模式按钮切换工作模式
- 位置模式：控制电机转到指定位置
- 速度模式：控制电机以指定速度运行
- 待机模式：电机停止运行
- 增量模式：相对当前位置移动

### 3. 设置目标值
- 在对应输入框输入目标值
- 点击"设置"按钮应用

### 4. 调整PID参数
- 修改PID参数值
- 点击"应用PID"按钮
- 参数会自动乘以1000后发送

### 5. 实时监控
- 点击"开始监控"按钮
- 实时显示当前位置、速度、模式等信息
- 点击"停止监控"结束监控

## 寄存器映射

### 控制寄存器（可读写）
- 0x0000: 控制字（bit15=启动标志，bit0-3=模式）
- 0x0001: 模式设置
- 0x0002-0x0005: 目标位置（64位，4个寄存器）
- 0x0006-0x0007: 目标速度（32位，2个寄存器）
- 0x0008-0x000A: 位置环PID（Kp, Ki, Kd）
- 0x000B-0x000D: 速度环PID（Kp, Ki, Kd）
- 0x000E: 死区
- 0x000F: 最大输出
- 0x0010: 启动模式配置
- 0x0011: 电机方向
- 0x0012: 编码器方向
- 0x0014: MODBUS从机地址
- 0x0015: MODBUS波特率
- 0x0016: 设置当前位置为原点（写1触发）

### 状态寄存器（只读）
- 0x0100-0x0103: 当前位置（64位）
- 0x0104-0x0105: 当前速度（32位）
- 0x0106: 当前模式
- 0x0107: 状态字

## 注意事项

1. 确保STM32固件已正确烧录
2. 检查串口连接是否正常
3. PID参数修改后需要点击"应用"按钮
4. 监控功能会持续读取状态寄存器，可能影响通信性能
