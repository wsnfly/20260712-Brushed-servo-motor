# MODBUS RTU 电机控制器调试工具

## 功能特性

- 串口连接管理（支持自动扫描串口）
- 实时状态监控（位置、速度、模式、PWM、电流、电压、PID调试数据）
- 11种模式切换（位置、速度、位置速度、开环、外部目标位置/速度、待机、4种ADC模式）
- 目标值设置（位置、速度）
- 三环PID参数在线调整（位置环、速度环、电流环，含双套PID自动切换）
- 电流环配置（使能、PID参数、零点标定、过流保护、电流限幅、电流死区、前馈系数）
- ADC功能配置（PC2/PC3模式、最小/最大值范围、双死区、滤波窗口）
- 堵转保护配置（使能、误差阈值、持续时间）
- PB4/PB5引脚功能配置（10种功能、极性、限位方向、预设位置/速度）
- 多通道数据采集与波形显示（1~4通道，matplotlib绘图，支持24种采集类型）
- 加速表生成工具（自定义主频/速度/加速度/表长度，写入Flash）
- 步进加减速参数配置（最大/最小速度、目标位置、使能控制）
- 设置当前位置为原点（编码器清零+目标位置同步）
- 复位功能配置（堵转复位/开关精确复位、方向、速度、距离）
- 通信日志记录

## 安装依赖

```bash
pip install -r requirements.txt
```

依赖包：pyserial（串口通信）、matplotlib（波形绘制）、numpy（数据处理）

## 运行程序

```bash
python modbus_debugger.py
```

## 界面布局

界面采用左右分栏设计（可拖动调整比例）：

**左侧 — 配置区（可滚动）**
- 串口配置：串口号、波特率、从机地址
- 模式控制：11种模式按钮
- 目标位置/速度设置
- PID参数：位置环、速度环（含电流环使能时的双套PID）
- 电流环配置：使能、PID、标定、过流保护、限幅、死区、前馈
- ADC功能配置：PC2/PC3模式、速度/PWM/位置范围、死区、滤波
- 堵转保护配置
- PB4/PB5引脚配置：功能、极性、限位方向、预设位置/速度
- 其他参数：死区、最大输出、电机方向、编码器方向、启动方式等

**右侧 — 监控区（可滚动）**
- 实时状态显示：位置、速度、模式、PWM、电流、电压、状态字
- 三环PID调试数据：位置环/速度环/电流环的 error/P/I/D
- 数据采集波形图：matplotlib 实时绘图，支持多通道叠加显示
- 通信日志

## 使用说明

### 1. 连接串口
- 选择正确的串口号（如 COM3）
- 设置波特率（默认 115200）
- 设置从机地址（默认 1）
- 点击"连接"按钮

### 2. 设置模式
- 点击模式按钮切换工作模式
- 位置模式(0)：控制电机转到指定位置
- 速度模式(1)：控制电机以指定速度运行
- 位置速度模式(2)：目标位置按速度累加，梯形加减速效果
- 开环模式(3)：速度值直接映射到PWM
- 外部目标位置(4)/速度(5)：PB4/PB5电平选择预设值
- 待机模式(6)：关闭PWM，保留编码器计数
- ADC模式(7~10)：PC2/PC3电位器控制速度/PWM/位置

### 3. 设置目标值
- 在对应输入框输入目标值
- 点击"设置"按钮应用
- 位置为64位整数，速度为32位整数

### 4. 调整PID参数
- 修改PID参数值
- 点击"应用PID"按钮
- 参数会自动乘以100后发送（电流环Kd乘以1000）
- 电流环使能时自动切换到电流模式PID参数集

### 5. 电流环配置
- 设置零电流ADC标定值（默认2048）和转换系数（默认4883）
- 配置电流环PID参数
- 设置过流保护阈值和电流限幅
- 点击"使能电流环"开启三环级联控制
- 可选配置电流死区和前馈系数

### 6. 数据采集
- 选择采集类型（转速/PWM/位置/电流/PID输出等24种）
- 设置采集通道数（1~4通道同步采集）
- 设置采集点数和分频值（采样率）
- 点击"开始采集"
- 采集完成后波形自动显示在右侧图表中
- 多通道数据以不同颜色叠加显示

### 7. 加速表生成
- 菜单栏 -> 文件 -> 加速表生成
- 输入主频(timc)、最小速度(u)、加速度(a)、表长度(len)
- 点击"计算并写入Flash"
- 等待进度完成（0~1000）
- 可随时恢复ROM默认表

### 8. 实时监控
- 点击"开始监控"按钮
- 实时显示当前位置、速度、模式、PWM、电流、电压等信息
- 三环PID调试数据实时更新
- 点击"停止监控"结束监控

## 寄存器映射

完整寄存器映射详见 `docs/MODBUS_使用说明.md`。

### 主要寄存器区间

| 区间 | 属性 | 用途 |
|------|------|------|
| 0x0000~0x0031 | 读写 | 基础控制（模式、目标值、PID、方向、引脚配置等） |
| 0x0032~0x0038 | 读写 | 复位精调、外部目标速度 |
| 0x003A~0x003F | 读写 | 数据采集配置 |
| 0x0040~0x0044 | 读写 | 堵转保护 |
| 0x0045~0x004D | 读写 | 电流环（使能、PID、标定、过流保护） |
| 0x004E~0x0061 | 读写 | ADC功能（PC2/PC3模式、范围、死区） |
| 0x0062~0x006A | 读写 | 电流限幅、双套PID、电流死区、ADC滤波 |
| 0x006B~0x0091 | 读写/只读 | 步进加减速参数 |
| 0x0092~0x009A | 读写/只读 | 加速表计算 |
| 0x009B | 读写 | 电流环前馈系数 |
| 0x009C~0x009F | 读写 | 多通道采集配置 |
| 0x0100~0x0127 | 只读 | 状态寄存器（位置、速度、PWM、电流、三环PID调试数据） |
| 0x0200~0x15FF | 只读 | 采集数据缓冲区（5120个int16，10KB） |

## 配置文件

- `motor_config.json`：默认电机参数配置
- `motor_config.csv`：参数配置CSV格式
- `大电机参数.json`：大电机专用参数配置

## 注意事项

1. 确保STM32固件已正确烧录
2. 检查串口连接是否正常
3. PID参数修改后需要点击"应用"按钮
4. 监控功能会持续读取状态寄存器，可能影响通信性能
5. 电流环使能前请先配置电流模式PID参数(0x0063~0x0068)，否则可能振荡
6. 数据采集时建议降低监控频率，避免通信拥堵
7. 加速表写入Flash需要几秒钟，期间请勿断电
8. 多通道采集时每通道实际点数 = 总点数 / 通道数
