# 有刷直流伺服电机控制器 — 程序功能说明

## 一、概述

本项目基于 **STM32F103RBT6** 微控制器，实现了一款功能完整的有刷直流伺服电机控制器。支持位置模式、速度模式、位置速度模式、开环模式、外部目标位置/速度模式、待机模式、以及四种 ADC 模拟量控制模式共 11 种运行模式。配备 MODBUS RTU 工业总线通信接口（RS485），支持三环级联 PID 控制（位置环-速度环-电流环）、步进加减速轨迹规划、多通道数据采集、堵转与过流保护等功能，可通过上位机远程配置和监控。

## 二、硬件架构

| 外设 | 功能 | 引脚 |
|------|------|------|
| TIM1 | 100µs 定时中断（MODBUS超时检测 + PID定时器 + 编码器合成） | — |
| TIM2 | 步进加减速定时中断（梯形速度规划） / 10µs 脉冲边沿检测 | — |
| TIM3 | 编码器接口（4倍频模式，64位扩展计数） | PA6=CH1(A相), PA7=CH2(B相) |
| TIM4_CH1 | H桥正向PWM | PB6 |
| TIM4_CH2 | H桥使能1（常开100%） | PB7 |
| TIM4_CH3 | H桥反向PWM | PB8 |
| TIM4_CH4 | H桥使能2（常开100%） | PB9 |
| USART1 | MODBUS RTU 通信 | PA9=TX, PA10=RX |
| PA11 | RS485 方向控制 (DE/RE) | PA11 |
| PB4/PB5 | 可配置多功能数字输入引脚（EXTI中断） | PB4, PB5 |
| ADC1_CH10 | 供电电压监测（分压100K:10K，实际电压=ADC×11） | PC0 |
| ADC1_CH11 | 电流采样（INA240A1PWR 增益20V/V + 10mΩ电阻） | PC1 |
| ADC1_CH12 | 外部ADC输入1（可配置ADC控制模式） | PC2 |
| ADC1_CH13 | 外部ADC输入2（可配置ADC控制模式） | PC3 |

ADC1 工作在 DMA 循环扫描模式，4个通道连续转换，无需 CPU 干预。

## 三、软件架构

### 3.1 模块划分

```
main.c                  — 主程序入口、外设初始化、主循环
├── motor_control.c/h   — 伺服电机控制核心（三环PID、模式管理、保护机制）
├── modbus.c/h          — MODBUS RTU 从机协议栈（寄存器读写、帧处理）
├── encoder.c/h         — 编码器模块（64位位置合成、速度读取）
├── input.c/h           — PB4/PB5 输入处理（脉冲/方向/限位/复位/停止/启动）
├── ajiajiansu.c/h      — 步进电机加减速算法（梯形速度规划、加速表）
├── apwmliebiao.h       — ROM 加速表（10025点查表）
├── afangkaobei.c/h     — 防拷贝保护
└── stm32f1xx_it.c      — 中断服务函数
```

### 3.2 工作模式 (12种)

| 模式 | 值 | 描述 |
|------|-----|------|
| **位置模式** | 0 | PID位置闭环，控制电机精确到达目标位置 |
| **速度模式** | 1 | PID速度闭环，控制电机以目标速度持续运转 |
| **位置速度模式** | 2 | 目标位置按速度累加，走位置PID，实现平滑速度控制 |
| **开环模式** | 3 | 速度值直接映射到PWM输出，无反馈 |
| **外部目标位置模式** | 4 | PB4/PB5电平选择预设目标位置，走位置PID |
| **外部目标速度模式** | 5 | PB4/PB5电平选择预设目标速度，走速度PID |
| **待机模式** | 6 | 关闭PWM输出，保留编码器计数和速度计算 |
| **ADC转速模式** | 7 | ADC值(0~1)映射到预设速度范围，走速度PID |
| **ADC位置转速模式** | 8 | ADC值(0~1)映射到预设速度范围，走位置速度PID |
| **ADC开环模式** | 9 | ADC值(0~1)映射到预设PWM范围，直接输出 |
| **ADC位置模式** | 10 | ADC值(0~1)映射到预设位置范围，实时给目标位置走位置PID |
| **外部目标位置速度模式** | 11 | PB4/PB5电平选择预设速度，位置按速度累加(无累计误差)，走位置PID |

### 3.3 控制流程

```
TIM1 100µs 中断
  ├── sys_time_100us++              → 系统时间
  ├── Encoder_Synthesize()          → 64位编码器位置合成
  ├── MODBUS_OnTimeoutTick()        → MODBUS帧间超时检测
  └── MotorControl_TimerTick100us()
        ├── (每10次 ≈ 1ms) 速度环PID运算（级联模式）
        ├── (每10次 ≈ 1ms) 电流环PID运算（电流环使能时）
        └── (每50次 ≈ 5ms) MotorControl_Update()
              ├── 编码器速度计算 + 16级移动平均滤波
              ├── 堵转保护检测
              ├── 脉冲累加（PB4/PB5输入）
              ├── 位置环 PID 运算
              ├── 抗积分饱和
              ├── 限位开关钳制
              └── Motor_SetPWM() → TIM4 占空比

TIM2 中断
  ├── (步进加减速使能时) pwmzhongduankongzhi()
  │     └── 梯形速度规划 → 实时更新电机目标位置
  └── (脉冲输入模式) PB4/PB5边沿检测 + 脉冲累加

主循环 (5ms周期)
  ├── MotorControl_ProcessInputs()  → 引脚输入处理（停止/复位/启动按钮）
  ├── 外部ADC滤波（滑动平均）
  ├── ADC模式目标值计算（归一化 + 死区处理）
  ├── 数据采集（多通道，按分频周期采样）
  └── MODBUS_Process()             → MODBUS帧解析与响应
```

### 3.4 三环级联 PID 控制

控制器支持三环级联 PID：位置环（5ms）→ 速度环（1ms）→ 电流环（100µs），各环独立周期运行。

**位置环 PID（5ms周期）**
- 比例 P + 积分 I（过零清零）+ 微分 D（误差导数阻尼）
- 步进加减速模式下增加速度前馈 FF = pos_Kff × target_vel，消除移动目标时的周期性抖动
- 级联模式（max_run_speed > 0）下输出 target_velocity 给速度环

**速度环 PID（1ms周期）**
- 比例 P + 积分 I（小误差死区）+ 微分 D（速度变化率）
- 仅在级联模式（位置模式 + max_run_speed > 0）下运行
- 输出 current_target 给电流环或直接作为 PWM

**电流环 PID（100µs周期）**
- 比例 P + 积分 I + 微分 D + 速度前馈 Kff（反电动势补偿）
- 使能后位置/速度环输出作为电流目标，电流环输出最终 PWM
- 关闭时位置/速度环输出直接作为 PWM（原行为）
- 支持电流限幅（平滑限制）和过流保护（超限关断）

**双套 PID 参数自动切换**
电流环改变被控对象特性（电压控制 vs 电流控制），因此保存两套 PID 参数：
- 电流环关闭：使用 pos_Kp/Ki/Kd, spd_Kp/Ki/Kd（电压模式参数）
- 电流环使能：使用 pos_Kp_cur/Ki_cur/Kd_cur, spd_Kp_cur/Ki_cur/Kd_cur（电流模式参数）

**抗积分饱和**：输出饱和时回退本次积分累积，防止积分深度饱和。

### 3.5 MODBUS 协议

| 项目 | 说明 |
|------|------|
| 物理层 | RS485 (TTL UART + DE方向控制) |
| 功能码 | 0x03(读), 0x06(写单寄存器), 0x10(写多寄存器) |
| 帧检测 | 3.5字符时间空闲中断检测（随波特率动态调整） |
| CRC16 | 多项式 0xA001, 查表法, 小端序 |
| 控制寄存器 | 0x0000~0x009F (可读写) |
| 状态寄存器 | 0x0100~0x0127 (只读) |
| 数据缓冲区 | 0x0200~0x15FF (只读, 5120个int16, 10KB) |
| 波特率 | 在线可切换，支持 9600~115200 |
| 从机地址 | 在线可修改，保存到Flash |

### 3.6 多功能数字输入引脚 (PB4/PB5)

每个引脚可独立配置为 10 种功能之一：

| 功能 | 值 | 说明 |
|------|-----|------|
| 脉冲输入 | 0 | 每个上升沿改变电机目标位置 |
| 方向信号 | 1 | 脉冲模式下的方向控制 |
| 原点位置开关 | 2 | 堵转/开关精确复位时作为原点触发信号 |
| 限位开关 | 3 | 阻止指定方向的运动 |
| 目标位置电平 | 4 | 外部目标位置模式下选择预设位置 |
| 目标速度电平 | 5 | 外部目标速度模式/外部目标位置速度模式下选择预设速度 |
| 执行复位操作 | 6 | 按钮按下时启动一次复位流程（按home_mode配置执行） |
| 无功能 | 7 | 引脚不参与任何逻辑 |
| 停止 | 8 | 按钮按下时PWM输出为0，松开后恢复 |
| 启动标志位触发 | 9 | 引脚有效边沿触发启动标志位（需start_mode=1，用于多电机同步启动） |

支持极性选择（高电平/上升沿有效 或 低电平/下降沿有效）和限位方向选择。

**电子齿轮（脉冲倍频/分频）**
- 外部脉冲输入后，实际电机移动量 = 输入脉冲 × (分子/分母)
- 分子/分母可设1~65535，通过MODBUS寄存器0x00A1/0x00A2配置
- 倍频（分子>分母）：适用于脉冲检测频率受限（如3KHz），通过倍频提高等效速度
- 分频（分子<分母）：配合高频脉冲源实现精细分辨率
- 使用小数累加器消除整数除法截断误差，参数保存到Flash

### 3.7 ADC 模拟量控制 (PC2/PC3)

PC2/PC3 可独立配置为 4 种 ADC 控制模式或无功能（冲突时 PC2 优先）。ADC 值归一化为 0~1，映射到可配置的最小值~最大值范围。

| ADC功能 | 值 | 对应电机模式 | 控制对象 |
|---------|-----|-------------|---------|
| 无功能 | 0 | — | 不启用ADC控制 |
| ADC转速 | 1 | ADC转速模式(7) | ADC值映射到预设速度范围，走速度PID |
| ADC位置转速 | 2 | ADC位置转速模式(8) | ADC值映射到预设速度范围，走位置速度PID |
| ADC开环 | 3 | ADC开环模式(9) | ADC值映射到预设PWM范围，直接输出 |
| ADC位置 | 4 | ADC位置模式(10) | ADC值映射到预设位置范围，走位置PID |

ADC 处理特性：
- **滑动平均滤波**：窗口大小可配置（0~128），主循环5ms周期下延迟 4点≈20ms ~ 128点≈640ms
- **双死区控制**：两个独立死区，可设置位置（最小点/中位点/最大点）和宽度，防止电位器在停止位置附近因噪声导致电机缓慢转动
- **最小值/最大值范围**：所有预设值均可为负数，支持双向控制

### 3.8 电流环与保护机制

**电流采样硬件**
- INA240A1PWR（增益20V/V）+ 10mΩ采样电阻
- 总跨阻 0.2 V/A，3.3V ADC，零电流=1.65V（ADC=2048）
- 满量程 ±8.25A 对应相对电流 ±1000
- 1A实际 ≈ 121相对单位

**电流标定**
- 零电流ADC值（offset）默认2048，可通过MODBUS在线标定
- ADC到相对电流转换系数（scale）默认 1000/2048 ≈ 0.488
- 支持自动零点标定（写0x0049=0xFFFF触发，64次ADC平均）
- 支持开机自动零点校准（0x00A0）：开启后每次开机自动校准零点电流，结果不保存Flash，避免频繁烧写；关闭时使用Flash保存的offset，手动校准后存Flash

**保护机制**
- **电流限幅**：平滑限制电流目标绝对值，不触发保护（0=不限制）
- **过流保护**：实际电流超限时关闭输出，需手动复位（0=关闭）
- **电流死区**：实际电流绝对值小于此值且目标为0时强制PWM=0，防止静止时细微电流
- **堵转保护**：误差持续超限达设定时间后关闭输出，需手动复位
- **速度前馈**：PWM += Kff × velocity，补偿高速反电动势，解决限流时速度下降问题

### 3.9 步进加减速位置模式

使能后，位置模式下目标位置不直接给PID，而是经过步进加减速算法（TIM2中断驱动梯形速度规划）生成平滑的中间位置轨迹，再实时写入电机目标位置。

**核心参数**
- 最大运行速度、最小/启动速度、预定目标位置（可通过MODBUS在线修改）
- 加速表：ROM默认表（10025点）或Flash自定义表（上位机计算写入）

**加速表自定义**
上位机通过MODBUS写入主频(timc)、最小速度(u)、加速度(a)、表长度(len)参数，触发STM32计算加速表并存入Flash（支持进度查询）。

**位置环速度前馈**
步进加减速模式下目标位置持续移动，D项改用误差导数（目标匀速时D≈0），并增加显式前馈 FF = pos_Kff × target_vel，消除积分windup导致的周期性速度抖动。

### 3.10 数据采集系统

支持 1~4 通道同步采集，缓冲区最大 5120 点（10KB），数据交错存储（类似STM32 ADC扫描模式）。

**采集类型**
- 基础类型：转速、PWM、位置、电流、供电电压、PC2/PC3外部ADC
- PID调试类型：电流环开启/关闭时的位置环/速度环/电流环各 P/I/D 输出
- 误差类型：位置误差、速度误差

**采集控制**
- 分频值可配置（1=100µs采样, 50=5ms采样, 默认50）
- 采集点数可配置（1~5120）
- 通过MODBUS启动/停止采集，读取采集状态和进度
- 采集数据通过 0x0200~0x15FF 寄存器区读取

### 3.11 复位功能

支持两种复位模式：

**堵转检测复位**
- 以配置速度向复位方向运动，检测到堵转（速度低于阈值）时判定为原点
- 碰撞后自动后退指定距离
- 可配置复位方向、电流限制、最大搜索距离

**开关精确复位**
- 使用限位开关低速来回检测精确位置
- 可配置低速检测速度和来回检测次数

**触发方式**
- 开机自动复位（可配置开关）
- MODBUS手动触发
- PB4/PB5配置为"执行复位操作"按钮（带300ms防抖冷却，复位进行中不重复触发）

### 3.12 参数持久化

所有配置参数（PID参数、方向、地址、波特率、引脚功能、ADC配置、电流环参数、步进加减速参数、电子齿轮、中断优先级等）自动保存到STM32 Flash，上电自动恢复。使用魔数校验确保数据有效性。

### 3.13 中断优先级在线配置

通过MODBUS寄存器0x00A3~0x00A7可在线调整5个关键中断的抢占优先级（0~15，数值越小优先级越高），修改后立即生效并保存Flash。

| 中断 | 寄存器 | 默认 | 用途 |
|------|--------|------|------|
| USART1 | 0x00A3 | 1 | MODBUS串口通信 |
| TIM1 | 0x00A4 | 2 | 100μs PID控制 |
| TIM2 | 0x00A5 | 3 | 步进加减速 |
| EXTI4 | 0x00A6 | 1 | PB4脉冲输入 |
| EXTI9_5 | 0x00A7 | 1 | PB5脉冲输入 |

默认配置遵循：通信最高 > PID > 步进加减速，脉冲输入与PID同级靠硬件PR锁存保证不丢边沿。

Flash 空间分配：
- 电机配置页：0x0801FC00（1KB）
- 加速表头部：0x0801A000（1KB）
- 加速表数据：0x0801A400 起（最多20KB）

## 四、保护机制总览

1. **限位开关保护**：配置为限位功能的引脚激活时，阻止该方向运动
2. **最大运行速度限制**：所有模式下超速自动钳制输出为0
3. **最大输出限制**：PWM最大输出可配置（10~1000）
4. **堵转保护**：误差持续超限达设定时间后关闭输出，需手动复位
5. **过流保护**：实际电流超限时关闭输出，需手动复位
6. **电流限幅**：平滑限制电流目标，不触发保护
7. **电流死区**：静止时强制PWM=0，防止细微电流
8. **UART错误恢复**：ORE/FE/NE错误自动清除并重启接收
9. **MODBUS帧堆积保护**：上一帧未处理时丢弃新帧
10. **PID抗积分饱和**：输出饱和时停止积分累积
11. **死区保护**：位置模式误差在死区内停止输出，防止抖动
12. **防拷贝保护**：防止固件被非法复制
