# MODBUS RTU 使用说明

## 1. 通信参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 接口 | RS485/USART1 | PA9=TX, PA10=RX, PA11=DE(方向控制) |
| 波特率 | 115200 | 支持 9600/19200/38400/57600/115200 |
| 数据格式 | 8N1 | 8数据位, 无校验, 1停止位 |
| 从机地址 | 1 | 范围 1~247, 可通过MODBUS在线修改并保存到Flash |

## 2. 快速开始

### 2.1 连接硬件
- 将控制器 RS485 接口连接到 PC 的 USB-RS485 转换器
- 上位机打开串口调试工具 (波特率 115200, 8N1)

### 2.2 读取电机当前位置
发送: `01 03 01 00 00 04` (读取 0x0100~0x0103 四个寄存器)

响应解析: 返回的 8 字节数据 = 64 位有符号整数（大端序），单位：编码器脉冲数。

### 2.3 让电机转到位置 10000
发送: `01 10 00 02 00 04 08 00 00 00 00 00 00 27 10` 及 CRC

位置值 10000 = 0x00002710, 分 4 个寄存器(每个16位)发送。

### 2.4 让电机以速度 800 脉冲/秒运转
```
01 06 00 00 00 01           → 切换为速度模式
01 10 00 06 00 02 04 00 00 03 20  → 目标速度 = 800
```

## 3. 支持的功能码

| 功能码 | 名称 | 用途 |
|--------|------|------|
| 0x03 | 读保持寄存器 | 读取当前状态、位置、速度、PID调试数据等 |
| 0x06 | 写单个寄存器 | 模式切换、单值设置 |
| 0x10 | 写多个寄存器 | 设置64位目标位置、PID参数批量写入 |

## 4. 模式定义

| 值 | 模式 | 说明 |
|----|------|------|
| 0 | 位置模式 | PID位置闭环 |
| 1 | 速度模式 | PID速度闭环 |
| 2 | 位置速度模式 | 目标位置按速度累加，走位置PID |
| 3 | 开环模式 | 速度值直接映射到PWM |
| 4 | 外部目标位置模式 | PB4/PB5电平选择预设位置 |
| 5 | 外部目标速度模式 | PB4/PB5电平选择预设速度 |
| 6 | 待机模式 | 关闭PWM，保留编码器计数 |
| 7 | ADC转速模式 | ADC值映射速度，走速度PID |
| 8 | ADC位置转速模式 | ADC值映射速度，走位置速度PID |
| 9 | ADC开环模式 | ADC值映射PWM，直接输出 |
| 10 | ADC位置模式 | ADC值映射位置，走位置PID |
| 11 | 外部目标位置速度模式 | PB4/PB5电平选择预设速度，位置按速度累加(无累计误差)，走位置PID |

### 5.6 开机自动零点电流校准 (0x00A0)

| 地址 | 名称 | 说明 |
|------|------|------|
| 0x00A0 | 开机自动零点校准 | 0=关闭(默认), 1=开启 |

**功能说明：**
- **关闭(0, 默认)**：使用Flash中保存的零点offset。手动校准通过写0x0049=0xFFFF触发，校准结果保存到Flash。
- **开启(1)**：每次开机自动读取ADC零电流offset（64次平均），结果仅用于本次运行，不保存Flash。适合零点会随温度漂移的场景，避免频繁烧写Flash导致寿命损耗。

> 写入0x00A0本身会保存到Flash，使下次开机按此配置执行。仅校准结果不存Flash。

### 5.7 电子齿轮(脉冲倍频/分频) (0x00A1~0x00A2)

| 地址 | 名称 | 说明 |
|------|------|------|
| 0x00A1 | 电子齿轮分子 | 1~65535, 默认1 |
| 0x00A2 | 电子齿轮分母 | 1~65535, 默认1 |

**功能说明：**
外部脉冲输入（PB4/PB5配置为脉冲模式）后，实际电机移动量 = 输入脉冲 × (分子/分母)。

- **倍频**（分子 > 分母）：例如 2/1 = 每个输入脉冲移动2步。适用于脉冲检测频率受限（如3KHz），通过倍频提高等效速度。
- **分频**（分子 < 分母）：例如 1/2 = 每2个输入脉冲移动1步。适用于配合高频脉冲源实现精细分辨率。
- **直通**（分子 = 分母 = 1，默认）：1:1，每个输入脉冲移动1步，与原有行为一致。

固件使用小数累加器消除整数除法截断误差，确保长期累积无精度损失。例如3/2倍频：第1个脉冲移动1步（余1），第2个脉冲移动2步（余0），平均1.5步/脉冲。

> 修改齿轮比时自动清零小数累加器。齿轮比参数保存到Flash，掉电不丢失。

### 5.8 中断优先级配置 (0x00A3~0x00A7)

| 地址 | 名称 | 说明 |
|------|------|------|
| 0x00A3 | USART1中断优先级 | 0~15, 默认1, 数值越小优先级越高 |
| 0x00A4 | TIM1中断优先级 | 0~15, 默认2 |
| 0x00A5 | TIM2中断优先级 | 0~15, 默认3 |
| 0x00A6 | EXTI4中断优先级 | 0~15, 默认1 |
| 0x00A7 | EXTI9_5中断优先级 | 0~15, 默认1 |

**功能说明：**
STM32F103有4位抢占优先级（0~15），数值越小优先级越高。通过这些寄存器可在线调整各中断的抢占优先级，修改后立即生效并保存到Flash。

| 中断 | 默认 | 用途 | 调整建议 |
|------|------|------|----------|
| USART1 | 1 | MODBUS串口通信 | 保持最高（1），避免ORE溢出丢包 |
| TIM1 | 2 | 100μs PID控制 | 中等优先级，被通信短时抢占不影响控制 |
| TIM2 | 3 | 步进加减速 | 最低优先级，不抢PID和通信 |
| EXTI4 | 1 | PB4脉冲输入 | 与TIM1同级，靠硬件PR锁存保证不丢边沿 |
| EXTI9_5 | 1 | PB5脉冲输入 | 同EXTI4 |

> 注意：EXTI优先级不应高于TIM1（数值更小），否则高频脉冲会频繁打断PID导致周期抖动。参数保存到Flash，掉电不丢失。

## 6. 典型应用场景

### 场景一：位置模式点对点定位
```
① 写 0x0001=0          → 直接启动
② 写 0x0000=0          → 位置模式
③ 写 0x0002~0x0005     → 设置目标位置
④ 电机自动运行到目标位置
```

### 场景二：速度模式连续运转
```
① 写 0x0000=1          → 速度模式
② 写 0x0006~0x0007     → 设置目标速度
③ 电机持续运转
④ 写目标速度=0         → 停止
```

### 场景三：位置速度模式(梯形加减速效果)
```
① 写 0x0001=1          → 标志位启动
② 写 0x0000=2          → 位置速度模式
③ 写 0x0006~0x0007     → 设置目标速度
④ 写 0x0010=1          → 启动
⑤ 写目标速度=0         → 停止
```

### 场景四：外部IO控制目标位置
```
① 写 0x0000=4          → 外部目标位置模式
② 配置PB4/PB5功能为4  → 目标位置电平
③ 写 PB4/PB5 预设位置
④ PB4 输入有效 → 到达PB4预设位置
⑤ PB5 输入有效 → 到达PB5预设位置
⑥ 都无效 → 回到原点位置(0)
```

### 场景五：外部IO控制目标速度
```
① 写 0x0000=5          → 外部目标速度模式
② 配置PB4/PB5功能为5  → 目标速度电平
③ 写 0x0035~0x0038     → 设置PB4/PB5预设速度
④ PB4 输入有效 → 以PB4预设速度运转
⑤ PB5 输入有效 → 以PB5预设速度运转
⑥ 都无效 → 停止
```

### 场景六：ADC电位器控制转速
```
① 写 0x004E=1          → PC2配置为ADC转速模式
② 写 0x0050~0x0051     → ADC最大速度(如10000)
③ 写 0x0057~0x0058     → ADC最小速度(如0, 可为负数)
④ 写 0x005F=200        → ADC死区1宽度(防止停止位置抖动)
⑤ 写 0x006A=16         → ADC滤波窗口(16点≈80ms)
⑥ PC2接电位器 → 转速随电位器线性变化
```

### 场景七：电流环三环级联控制
```
① 写 0x0049=2048       → 零电流ADC标定值
② 写 0x004A=4883       → ADC转换系数(×10000)
③ 写 0x0046~0x0048     → 电流环PID参数
④ 写 0x0063~0x0068     → 电流环使能时的位置/速度环PID参数
⑤ 写 0x004B=6060       → 过流保护阈值(≈5A)
⑥ 写 0x0062=6060       → 电流限幅(≈5A)
⑦ 写 0x009B=200        → 电流环前馈系数(0.02)
⑧ 写 0x0045=1          → 使能电流环
⑨ 写 0x0000=0          → 位置模式(三环级联)
```

### 场景八：步进加减速位置模式
```
① 写 0x006B~0x006E     → 最大运行速度
② 写 0x006F~0x0072     → 最小/启动速度
③ 写 0x0091=1          → 使能步进加减速
④ 写 0x0000=0          → 位置模式
⑤ 写 0x0073~0x0076     → 预定目标位置
⑥ 电机按梯形速度曲线平滑运行到目标位置
```

### 场景九：自定义加速表
```
① 写 0x0092~0x0093     → 主频(如32000000)
② 写 0x0094            → 最小速度(如500)
③ 写 0x0095~0x0096     → 加速度(如320000)
④ 写 0x0097            → 表长度(最大10015)
⑤ 写 0x0098=1          → 触发计算
⑥ 轮询 0x009A          → 等待进度=1000(完成)
⑦ 写 0x0098=2          → 恢复ROM默认表(如需)
```

### 场景十：多通道数据采集
```
① 写 0x003E            → 通道1采集类型(如0=转速)
② 写 0x009D            → 通道2采集类型(如1=PWM)
③ 写 0x009C=2          → 采集通道数=2
④ 写 0x003F=2000       → 采集点数(每通道1000点)
⑤ 写 0x003B=50         → 分频值(5ms采样)
⑥ 写 0x003A=1          → 启动采集
⑦ 轮询 0x003D          → 等待状态=2(完成)
⑧ 读 0x0200~0x0FFF     → 读取采集数据(交错存储)
```

### 场景十一：三环PID调试
```
① 写 0x0045=1          → 使能电流环
② 写 0x0000=0          → 位置模式
③ 设置目标位置/速度
④ 读 0x0116~0x0124     → 批量读取三环PID调试数据
   位置环: 0x0116~0x0119 = error, P, I, D
   速度环: 0x011A~0x011D = error, P, I, D
   电流环: 0x011E~0x0121 = error, P, I, D
   中间量: 0x0122=target_velocity, 0x0123=current_target, 0x0124=current_actual
⑤ 根据调试数据调整PID参数
```

## 7. 注意事项

1. **多字节写入请使用 0x10 功能码**：64位目标位置分4次写入时，固件在全部写完后才生效，避免中途应用半更新数据。

2. **PID参数范围**：写入值 = 实际值 × 100，如 Kp=7.0 则写入 700。负值用16位补码表示。电流环Kd为×1000（3位小数）。

3. **参数持久化**：PID参数、地址、波特率、引脚功能、ADC配置、电流环参数等修改后自动保存到Flash（每帧最多擦写一次）。步进加减速参数(0x006B~0x0076)写入立即生效但不落Flash。

4. **修改从机地址**：写 0x0014 后，响应帧仍用旧地址返回，之后设备立即切换到新地址。

5. **错误恢复**：通信异常时固件会自动清除错误标志并重启接收，无需手动干预。

6. **最大输出保护**：写入范围自动钳位在 10~1000，防止误设为0导致电机不动。

7. **帧间隔**：建议主机发送帧之间保留至少 5ms 间隔，确保固件有足够时间处理。

8. **电流环标定**：使能电流环前需先标定零电流ADC值(0x0049)和转换系数(0x004A)。默认值2048和4883适配 INA240A1PWR + 10mΩ电阻硬件。

9. **双套PID参数**：电流环使能/关闭时使用不同的PID参数集。使能电流环前请先配置 0x0063~0x0068 的电流模式PID参数，否则使用默认值可能导致振荡。典型值：电流模式Kp约为电压模式的1/3，Ki约为1/5。

10. **堵转/过流复位**：触发堵转(0x0043=1)或过流(0x004C=1)后，输出被关闭。需写0x0044=1或0x004D=1清除标志并恢复运行。

11. **ADC死区**：电位器控制时建议设置死区(0x005E~0x0061)，防止停止位置附近因噪声导致电机缓慢转动。死区位置可选最小点/中位点/最大点。

12. **数据采集缓冲区**：多通道采集时缓冲区数据交错存储，每通道实际点数 = 总点数 / 通道数。读取0x0200~0x15FF区域获取采集数据。
